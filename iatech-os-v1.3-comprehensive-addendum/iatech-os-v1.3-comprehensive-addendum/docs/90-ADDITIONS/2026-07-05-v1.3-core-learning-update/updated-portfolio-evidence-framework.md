# Portfolio and Evidence Framework v1.3

## Purpose

The portfolio should prove capability, not just list projects.

## Every Portfolio Project Should Include

- Problem identified
- Users/stakeholders
- Process or system analysed
- Tools chosen
- Why those tools were chosen
- AI assistance used
- Foundations learned
- Rebuild evidence
- Mastery challenge
- Deployment/live link where applicable
- Reflection
- Teaching or presentation evidence
- Tutor feedback
- Skills demonstrated
- Capabilities demonstrated

## Evidence Types

- GitHub link
- Vercel link
- Screenshot
- Video demo
- Process map
- Dataset/dashboard
- Prompt library entry
- Simulation link
- CMS plan
- Reflection
- Presentation slide
- Tutor review

## AI Use Disclosure

Students should document how AI helped and what they did independently.
