# Data Analysis Skill Domain

## Purpose

Data Analysis helps learners diagnose problems, discover patterns, and make better decisions.

This directly supports IATECH's mission to ease business processes.

## Learning Outcomes

Students should learn to:

- Collect data.
- Organize data in tables.
- Clean simple datasets.
- Create charts.
- Build dashboards.
- Interpret trends.
- Ask better questions from data.
- Avoid false conclusions.
- Use Python for simple analysis.
- Tell a story with data.

## MVP Tools

- Google Sheets or Excel concepts
- CSV files
- Simple charts
- Python basics
- Pandas introduction for advanced learners
- Dashboard thinking

## Example Missions

- Analyse class attendance patterns.
- Build a small business sales dashboard.
- Analyse survey responses.
- Track market prices.
- Create a student performance dashboard.
- Build a family budget tracker.

## AI Prompting

Students should learn how to ask AI to:

- suggest charts
- identify missing data
- explain trends
- check assumptions
- summarize insights
- propose next questions

## Assessment

Students must explain what the data shows, what it does not show, and what decision it supports.
