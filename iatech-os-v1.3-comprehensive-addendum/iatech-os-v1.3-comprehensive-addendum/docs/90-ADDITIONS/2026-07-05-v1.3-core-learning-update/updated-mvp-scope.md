# Updated MVP Scope v1.3

## Core MVP Promise

Students learn to identify problems, understand processes, use AI professionally, build solutions, analyse data, create websites, use CMS tools, understand automation/robotics virtually, deploy projects, and present evidence of competence.

## Included in MVP

### Core Learning

- Critical Thinking
- Problem Solving
- Systems Thinking
- Business and Process Analysis

### AI

- AI Literacy
- Professional AI Communication
- Prompt Engineering
- AI-Assisted Development
- Vibe Coding as a rapid prototyping technique
- AI Learning Assistant

### Software

- Web Development
- Python Programming
- GitHub
- Vercel Deployment

### Data

- Spreadsheet thinking
- Data collection
- Data cleaning
- Charts
- Dashboards
- Python data analysis foundations
- Storytelling with data

### CMS and No-Code

- CMS concepts
- WordPress foundations
- Page builders such as Elementor
- Website structure
- Landing pages
- Forms
- Basic SEO
- Website management

### Hardware, Automation and Robotics

Virtual-first robotics and automation:

- Automation logic
- Sensors and actuators conceptually
- Arduino concepts
- Virtual circuit simulation
- Flowcharts
- IoT foundations
- Robotics problem solving

## Still Excluded From MVP

- Physical robotics kit dependency
- Advanced electronics lab
- AI grading
- Full AI project generation
- Marketplace
- Payments
- Native mobile app
- Video calling
- Full IDE
