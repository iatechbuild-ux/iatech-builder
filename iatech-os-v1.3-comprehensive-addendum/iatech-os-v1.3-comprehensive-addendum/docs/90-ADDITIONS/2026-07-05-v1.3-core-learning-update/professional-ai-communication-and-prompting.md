# Professional AI Communication and Prompt Engineering

## Purpose

Prompting should not be taught as memorizing magic phrases. It should be taught as professional communication with AI for different tasks.

## Core Principle

> Do not memorize prompts. Understand why they work.

## Prompting Domains

### 1. Learning Prompts

Used to understand concepts.

Framework:

Explain [concept] to a [learner level] using examples. Then test my understanding with questions.

### 2. Planning Prompts

Used before building.

Framework:

Act as a product architect. Help me plan [solution]. Ask me questions first before suggesting the structure.

### 3. Coding Prompts

Used for small modules.

Framework:

Here is my goal. Here is the component I want to build. Give me a small, understandable implementation and explain each part.

### 4. Debugging Prompts

Used to understand errors.

Framework:

Here is what I expected. Here is what happened. Here is my code/error. Help me find the root cause without rewriting everything.

### 5. Data Analysis Prompts

Used for interpretation and insight.

Framework:

Here is my dataset context. Help me identify patterns, possible issues, useful charts, and questions I should ask before drawing conclusions.

### 6. CMS and Website Prompts

Used to plan sites.

Framework:

Act as a website strategist. For this business, recommend website structure, pages, content sections, forms, and SEO basics. Explain whether CMS or custom code is better.

### 7. Robotics and Automation Prompts

Used for logic and simulation.

Framework:

Help me design the automation logic for [system]. Identify inputs, outputs, sensors, actuators, and step-by-step control flow.

### 8. Research Prompts

Used to explore and verify.

Framework:

Help me research [topic]. List what I need to verify, possible sources, assumptions, and questions before making a conclusion.

### 9. Business Process Prompts

Used for process improvement.

Framework:

Act as a business process analyst. Help me map the current process, identify bottlenecks, and suggest improvement options before recommending technology.

### 10. Review Prompts

Used for critique.

Framework:

Review my work. Identify strengths, weaknesses, risks, missing pieces, and improvements. Do not rewrite it unless I ask.

## Personal Prompt Library

Each learner should maintain a personal prompt library grouped by task type.

Categories:

- Learning
- Coding
- Debugging
- Data Analysis
- CMS
- Robotics
- Research
- Business Process
- Writing
- Presentation

## Product Implication

The app should include prompt libraries, prompt templates, prompt reflection, prompt versioning, and AI output evaluation activities.
