# Hardware, Automation and Robotics Domain

## Purpose

This domain introduces learners to physical computing, automation logic, sensors, actuators, IoT thinking, and robotics foundations.

For MVP, this is virtual-first.

## MVP Scope

Students learn:

- What robots are
- Sensors and actuators
- Inputs and outputs
- Automation logic
- Flowcharts
- Arduino concepts
- Virtual circuits
- IoT foundations
- Robotics problem solving
- Safety awareness

## Not in MVP

- Required physical robotics kits
- Advanced electronics lab
- Complex hardware builds
- Unsafe electrical experimentation

## Suggested Tools

- Tinkercad Circuits or similar virtual simulators
- Flowchart tools
- Pseudocode
- Simple block logic

## Example Missions

- Simulate a smart traffic light.
- Design an automatic door system.
- Create a farm moisture sensor concept.
- Simulate a smart dustbin logic.
- Design an obstacle detection robot flow.
- Build a home automation logic map.

## AI Prompting

Students should learn to ask AI to:

- identify inputs and outputs
- explain sensor logic
- design control flow
- find failure cases
- suggest simulation steps

## Assessment

Learners should explain the system logic, not just show a simulation.
