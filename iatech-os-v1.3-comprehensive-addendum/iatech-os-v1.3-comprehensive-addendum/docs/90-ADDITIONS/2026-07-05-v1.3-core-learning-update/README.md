# IATECH Builder v1.3 Core Learning Addendum

**Status:** Approved planning baseline  
**Owner:** IATECH Consult  
**Product:** IATECH Builder  
**Supersedes:** v1.2 addendum  

## Summary

This addendum updates the IATECH Builder product and learning architecture.

IATECH Builder is a **Future Builder Platform**. It develops problem solvers who use technology to improve businesses, communities, and lives.

The platform should not be understood as a coding app, LMS, AI chatbot, or STEM content library. It is a guided builder operating system where learners identify problems, understand them, choose tools, build solutions, deploy projects, and prove competence through evidence.

## New Core Learning Model

Every skill, mission, and pathway should follow:

**Experience → Understand → Rebuild → Master → Teach**

This allows students to see quick results with AI assistance, then return to foundations and rebuild with understanding.

## Updated Product Principle

> AI accelerates curiosity, but foundations create mastery.

## Updated MVP Skill Domains

- Critical Thinking
- Problem Solving
- Systems Thinking
- Business and Process Analysis
- AI Communication and Prompt Engineering
- AI-Assisted Development
- Web Development
- Python Programming
- Data Analysis
- CMS and No-Code Web Building
- Hardware, Automation and Robotics, virtual-first
- Product and Design Thinking
- Communication, Presentation and Leadership

## Key Architectural Change

The system should be capability-driven and skill-driven, not course-driven.

Courses should not be hardcoded. Skills, competencies, missions, evidence, and badges should be modular so future skill sets can be added without redesigning the platform.
