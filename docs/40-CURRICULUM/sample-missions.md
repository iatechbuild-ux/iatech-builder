# Sample Mission Library

> **v3 implementation note (2026-07-12):** These are idea-level samples. A mission is publishable only after it satisfies [`curriculum-quality-gates-v3.md`](curriculum-quality-gates-v3.md). The first fully specified sequence is [`python-explorer-course-v3.md`](python-explorer-course-v3.md).

> v2.0 re-frames every idea as a *problem*, not a *thing to build*, and tags tier + pathway. This is the seed set to author into full missions using [`mission-template.md`](mission-template.md). Start with **10 excellent ones**, not all of them.

Format: **Mission** — *the problem* · tier · pathway · lead competencies.

## Explorer (mostly Build-tier)

1. **This Is Me** — *A learner has no online presence to show who they are.* · Build · Explorer · web-development, communication.
2. **Club, Meet the School** — *A school club can't get members because no one knows it exists.* · Build · Explorer · web-development, product-thinking.
3. **Never Count Twice** — *A shopkeeper recounts stock nightly and makes errors.* · Build · Explorer · python, computational-thinking.
4. **Pass or Try Again** — *A teacher checks pass/fail by hand for 40 students.* · Build · Explorer · python, problem-solving.
5. **Small Goals, Big Change** — *A learner keeps abandoning goals with no way to track them.* · Build · Explorer · web-development, product-thinking.

## Builder (balanced Build/Ship)

6. **Who's Here Today** — *A tutor wastes class time taking attendance on paper.* · Ship · Builder · web-development, systems-thinking.
7. **Save My Seat** — *An event organizer can't track who's coming.* · Ship · Builder · web-development, design-thinking.
8. **Open for Business** — *A local baker has no way for customers to find or contact her.* · Ship · Builder · web-development, product-thinking.
9. **What Sold Today** — *A trader can't tell which products actually make money.* · Build · Builder · python, product-thinking.
10. **The Money Adds Up** — *A student can't see where pocket money goes.* · Build · Builder · python, critical-thinking.

## Innovator (mostly Ship-tier)

11. **The Community Board** — *A neighborhood has no shared place for notices and lost-and-found.* · Ship · Innovator · web-development, systems-thinking.
12. **Report the Waste** — *Illegal dumping has no easy way to be reported.* · Ship · Innovator · design-thinking, systems-thinking.
13. **Book the Clinic** — *A small clinic double-books patients.* · Ship · Innovator · product-thinking, web-development.
14. **The Farm Ledger** — *A smallholder farmer tracks harvests and costs on scattered paper.* · Ship · Innovator · python, product-thinking.
15. **Process, Improved** — *A small business has one slow, error-prone process; fix it.* · Ship · Innovator · systems-thinking, product-thinking.

## Authoring rule

Choose the exact set based on what learners are studying and the problem-solving outcome required — but never let a mission drift into "build a calculator" abstraction. Every one names a person.
