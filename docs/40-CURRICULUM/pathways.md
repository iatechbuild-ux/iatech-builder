# Pathways

## The rule (sharpened in v2.0)

**Skill determines pathway. Age governs safeguarding, reading level, consent, and peer-visibility defaults.** A gifted 10-year-old can be an Innovator in skill while still receiving age-appropriate protection and language. This resolves the v1 ambiguity where "age doesn't matter" was overstated.

## Explorer

*For learners new to building.*
- **Focus:** digital confidence, critical thinking basics, AI-literacy basics, HTML/CSS, simple Python, heavily guided projects.
- **Tier mix:** mostly Build-tier; one gentle Ship-tier near the end.
- **Expected exit level:** Application across core competencies; Independence in at least one.

## Builder

*For learners with some experience.*
- **Focus:** responsive web, basic JavaScript, Python foundations, prompt engineering, Git/GitHub, deployment, larger projects.
- **Tier mix:** balanced Build/Ship.
- **Expected exit level:** Independence in web development and problem solving; Application+ elsewhere.

## Innovator

*For advanced learners.*
- **Focus:** product & systems thinking, more complex web projects, APIs/databases later, community solutions, presentation, portfolio depth, and mentoring peers.
- **Tier mix:** mostly Ship-tier; introduces team/mentorship (Leadership level).
- **Expected exit level:** Independence across core; Leadership in at least one competency.

## Movement between pathways

- Placement sets the *starting* pathway ([`placement-assessment.md`](placement-assessment.md)).
- A learner moves up by **demonstrated competence**: approved projects that push the relevant competencies to the next mastery level, confirmed by a tutor. The promotion is logged (`placement_results.overridden_by` / competency ledger).
- Movement is not automatic on time or lessons; it is evidence-based (mastery model).
- A tutor can also recommend a move down if a learner is struggling, framed supportively and logged.

## Digital-confidence on-ramp (Explorer prerequisite)

Because some learners have never managed files, uploads, or accounts, Explorer opens with a short confidence on-ramp: create a folder, take and upload a screenshot, search safely, submit a file. A learner demonstrates readiness by completing these basic platform tasks independently.
