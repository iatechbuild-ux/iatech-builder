# Python

## Definition

In IATECH, Python is the tool for **logic, automation, and small useful programs** — taught through tiny real problems, never as abstract syntax drills.

## Why it matters here

Python gives quick wins on real tasks (a quiz, a calculator, a counter) and builds computational-thinking muscles that transfer everywhere. It also deploys and runs cheaply, which fits the low-cost constraint.

## Concept sequence (calibrated, not a dump)

Taught in this order, each unlocked by a mission that needs it:

1. Variables, input/output → *(a greeter, a simple form)*
2. Conditions → *(a result checker: pass/fail)*
3. Loops → *(an attendance counter)*
4. Lists → *(a score tracker)*
5. Functions → *(a reusable calculator)*
6. Simple error handling → *(guard against bad input)*
7. Basic file/data handling → *(a mini data-summary tool)*

Anything beyond this (classes, libraries, APIs) is deferred to later pathways.

## Anchor missions

Quiz game · expense calculator · attendance counter · result checker · guessing game · simple data summarizer.

## Common misconceptions

- *"I need to memorize syntax."* You need to think in steps; syntax is looked up.
- *"It ran, so it's correct."* Correct means it handles the edge cases too.
- *"Errors mean I failed."* Errors are the normal conversation between you and the computer.

## Tutor moves

- "Predict the output before you run it."
- "Walk me through it line by line as if you were the computer."
- "What happens if the input is empty or wrong?"
- "Where could you reuse a function instead of repeating code?"

## Teaching approach

Predict-the-output → run → debug → extend. Every Python mission ends with the learner explaining, in plain words, how their logic works — because explanation is the proof of understanding.

## Mastery rubric

| Level | What it looks like |
|------|--------------------|
| Awareness | Reads and predicts simple code; edits with help. |
| Application | Writes a small program from a spec with guidance. |
| Independence | Builds and debugs a program for a new problem, handling edge cases, unaided. |
| Leadership | Helps peers debug and explains logic clearly to others. |

## Assessment signals

Working program on a real task; handling of edge cases; quality of the plain-language explanation of the logic.
