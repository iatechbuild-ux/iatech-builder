# Problem Solving

## Definition

Problem solving is the repeated practice of turning a meaningful challenge into a **practical solution that improves someone's situation** — the spine that the other competencies serve.

## Why it matters here

It is the identity of the graduate: "solves problems and thinks differently." Every other competency (thinking, building, AI, design) is instrumental to this one. IATECH produces *problem solvers who use technology*, not *programmers looking for problems.*

## The cycle

Notice → Define → Investigate → Imagine → Choose → Build → Test → Improve → Share → Reflect

## The mission-design law

**Every mission starts with a person and a problem, never a language.**

- Weak: "Build a calculator."
- Strong: "A shopkeeper spends every evening re-adding totals and keeps making mistakes. Build something that helps."

## Common misconceptions

- *"Find a cool technology, then find a use for it."* Backwards. Start from the problem.
- *"The first solution is the solution."* First solutions are drafts.
- *"A working demo means the problem is solved."* Only if it helps the real person.

## Tutor moves

- "Who has this problem, and why does it matter to them?"
- "What's happening now? What have people already tried?"
- "Which solution is simplest and still helps?"
- "How will you test whether it actually helped?"
- "What will you improve in the next version?"

## Mission hooks

Every mission carries a problem statement, a decision log, a testing record, and a reflection. The portfolio shows *versions over time*, so improvement is visible, not just the final artifact.

## Progression (maps to mastery levels)

1. **Guided** — solves predefined problems (Awareness/Application).
2. **Assisted** — defines part of the problem (Application).
3. **Independent** — investigates authentic problems (Independence).
4. **Innovator/Leader** — tackles complex problems and mentors others (Leadership).

## Mastery rubric

| Level | What it looks like |
|------|--------------------|
| Awareness | Solves a clearly-specified problem with steps provided. |
| Application | Helps define the problem and chooses among given solutions. |
| Independence | Frames and investigates a real problem, and ships an improving solution, unaided. |
| Leadership | Mentors others through the full cycle and tackles ambiguous problems. |

## Assessment signals

Problem identification, investigation, decision justification, solution quality, iteration, real user value, reflection.
