# Design Thinking

## Definition

Design thinking is starting from the **person**, not the product: understand a real user, prototype quickly, test with them, and improve based on what you learn.

## Why it matters here

It is the guardrail against building something clever that nobody needs. It keeps "technology serves people" operational at the level of a single project.

## The model (the classic five, in learner language)

1. **Empathize** — talk to / observe the person with the problem.
2. **Define** — write the problem as *"[user] needs [need] because [insight]."*
3. **Ideate** — generate several options, not just the first idea.
4. **Prototype** — build the smallest thing that can be tried.
5. **Test** — put it in front of a real user and watch.

Then loop.

## Common misconceptions

- *"I know what users want."* Assumptions are hypotheses until a real user reacts.
- *"A prototype must be polished."* The point of a prototype is to learn cheaply, so rough is fine.
- *"Feedback is criticism."* Feedback is data; the goal is to find flaws early.

## Tutor moves

- "Who exactly is this for? Have you watched them struggle with it?"
- "State the need in one sentence: user, need, why."
- "What are three ways to solve this, not one?"
- "What's the smallest version you could test today?"
- "What did the user actually do — not what did they say?"

## Mission hooks

- Missions require a one-line user-need statement before any building begins.
- Intermediate/advanced missions require testing the artifact with at least one real person and recording what changed as a result.

## Mastery rubric

| Level | What it looks like |
|------|--------------------|
| Awareness | Names the intended user when prompted. |
| Application | Writes a user-need statement and gathers simple feedback with guidance. |
| Independence | Runs a small test with a real user and iterates unaided. |
| Leadership | Coaches peers to test with users and act on findings. |

## Assessment signals

Whether the user is real and specific; whether the design changed because of feedback; evidence of more than one idea considered.
