# Web Development

## Definition

Web development is the fastest route to a **visible, shareable, deployable** artifact — which makes it the backbone of the MVP's build-and-ship experience.

## Why it matters here

A learner can go from idea to a live URL a friend can open, in one mission. That visibility is motivating, and deployment on Vercel is free and simple, fitting the cost constraint.

## Concept sequence (mission-driven, never isolated)

1. How the web works (client, server, URL) → *(preview a page)*
2. HTML structure → *(a personal profile page)*
3. CSS styling + responsive layout → *(make it look right on a phone first)*
4. Basic accessibility → *(alt text, contrast, labels)*
5. Forms → *(an event registration page)*
6. Basic JavaScript interactivity → *(a simple quiz)*
7. Git/GitHub basics → *(save and share the code)*
8. Vercel deployment → *(ship a live link)*

## Anchor missions

Personal portfolio · school club page · local business landing page · event registration page · simple quiz app.

## Common misconceptions

- *"Learn HTML, then CSS, then JS separately, then build."* No — each is introduced inside a mission that needs it.
- *"Design for desktop, then shrink."* We design mobile-first, for the reference device.
- *"Accessibility is optional polish."* It is a correctness requirement (see [`30-DESIGN/accessibility.md`](../30-DESIGN/accessibility.md)).

## Tutor moves

- "Show me this on a phone-width screen. What breaks?"
- "Can someone using only a keyboard use this form?"
- "What is the one job of this page? Does the layout make that obvious?"

## Mission hooks

Each web mission includes a preview of the final product, a build checklist, code snippets, debugging tips, and — for Ship-tier — a guided deployment to Vercel with a live-link submission.

## Mastery rubric

| Level | What it looks like |
|------|--------------------|
| Awareness | Edits given HTML/CSS with guidance. |
| Application | Builds a small responsive page from a checklist with help. |
| Independence | Builds, styles, makes accessible, and deploys a page for a new brief unaided. |
| Leadership | Helps peers structure, debug, and deploy their pages. |

## Assessment signals

Structure and clarity; mobile responsiveness; accessibility basics; working links/forms; successful deployment (Ship tier); the learner's explanation of their choices.
