# Product Thinking

## Definition

Product thinking is moving from *"I built something"* to *"I built something useful that someone would actually use."* It adds the questions of value, audience, and trade-offs to a working artifact.

## Why it matters here

A learner can build a technically-correct thing that helps no one. Product thinking is the discipline of aiming the build at real value and knowing what to leave out.

## The model — Value questions

For any artifact, the learner answers:
1. **Who** is this for, specifically?
2. **What job** does it do for them?
3. **Why this** over what they do today?
4. **What's the smallest version** that delivers the value (the MVP mindset)?
5. **What did I deliberately leave out**, and why?
6. **How would I know it worked?** (a success signal)

## Common misconceptions

- *"More features means more value."* Usually the opposite; scope is a cost.
- *"If I like it, it's good."* The user's judgment beats the builder's taste.
- *"Done means feature-complete."* Done means it delivers the core value reliably.

## Tutor moves

- "If you could only keep one feature, which one earns its place?"
- "What's the one job this must do well?"
- "Why would someone use this instead of what they do now?"
- "How would you measure whether it helped?"

## Mission hooks

- Ship-tier missions require a one-line value statement and an explicit "what I left out and why."
- Innovator missions require a simple success signal (e.g., "the shopkeeper's nightly count now takes 2 minutes, not 20").

## Mastery rubric

| Level | What it looks like |
|------|--------------------|
| Awareness | States who a product is for when prompted. |
| Application | Prioritizes a core feature and names the value with guidance. |
| Independence | Scopes an MVP, cuts non-essential features, and defines a success signal unaided. |
| Leadership | Coaches peers to focus on value and resist scope creep. |

## Assessment signals

Clarity of the value statement; evidence of deliberate scoping (what was cut); presence of a success signal.
