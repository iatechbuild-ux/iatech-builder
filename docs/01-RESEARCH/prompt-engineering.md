# Prompt Engineering

## Definition

Prompt engineering is structured communication with an AI system to get a useful, verifiable result — while still doing your own thinking.

## Why it matters here

It is the practical craft that makes AI literacy actionable. A clear prompt gets a better draft; but the goal is never to outsource thinking — it is to get a *first draft worth critiquing*.

## The formula

**Role + Goal + Context + Constraints + Output format.**

> "Act as a friendly web-development tutor. Help me plan a simple landing page for a local bakery. Users are parents and students. Keep it simple. Give me sections, content ideas, and a layout — as a bulleted list."

## What learners should practice

- Be specific; provide context; state constraints.
- Ask for steps, examples, or a comparison of options.
- Ask the AI to explain an error message.
- **Verify** important claims before using them.
- Improve the prompt iteratively when the output is weak.

## Common misconceptions

- *"A longer prompt is always better."* Clarity beats length.
- *"One prompt should do it."* Good results come from iteration.
- *"Whatever it returns, I use."* The output is a draft to evaluate, not an answer to submit.

## Tutor moves

- "What role and goal did you give it? What context was missing?"
- "How would you change the prompt to fix what's wrong?"
- "Show me your before-and-after prompt and what improved."

## Mission hooks

Prompt-practice activities require the learner to submit: original prompt → output summary → improved prompt → final result → one-line reflection on what changed. The reflection is where critical thinking shows.

## Mastery rubric

| Level | What it looks like |
|------|--------------------|
| Awareness | Writes a basic prompt using the formula when prompted. |
| Application | Adds context and constraints and iterates once with guidance. |
| Independence | Iteratively refines prompts and verifies outputs unaided. |
| Leadership | Teaches peers to structure and refine prompts. |

## Assessment signals

Improvement between first and refined prompt; whether constraints/context were used; whether the learner verified rather than accepted the output.
