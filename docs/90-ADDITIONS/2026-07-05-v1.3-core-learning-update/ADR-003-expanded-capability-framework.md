# ADR-003: Expand MVP Into Capability-Based Future Builder Framework

**Status:** Accepted

## Decision

IATECH Builder will organize learning around capabilities, not courses.

## Capability Model

### 1. Think

- Critical Thinking
- Problem Solving
- Systems Thinking
- Design Thinking

### 2. Understand

- Business and Process Analysis
- User Research
- Requirements Gathering
- Data Analysis

### 3. Build

- Web Development
- Python Programming
- CMS and No-Code Web Building
- AI-Assisted Development
- Hardware, Automation and Robotics

### 4. Improve

- Debugging
- Testing
- Optimization
- Deployment
- Maintenance

### 5. Lead

- Communication
- Documentation
- Presentation
- Collaboration
- Leadership

## Rationale

Companies and communities do not only need people who know tools. They need people who can understand problems, choose tools, create solutions, improve systems, and communicate results.

## Product Implication

The app should track capabilities, skills, competencies, projects, evidence, and badges.
