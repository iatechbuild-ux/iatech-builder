# ADR-002: Adopt AI-Accelerated Learning Framework

**Status:** Accepted  
**Decision Type:** Educational Architecture  

## Context

The earlier model emphasized mission-based learning and problem-solving. This remains correct, but the emergence of AI-assisted development changes how students can become excited and productive quickly.

Many learners, including children, can build impressive first versions using AI tools. However, if this is not structured properly, they may become dependent on AI without understanding the foundations.

## Decision

IATECH Builder will adopt the following universal learning framework:

**Experience → Understand → Rebuild → Master → Teach**

This framework applies to every skill, including web development, Python, data analysis, CMS, robotics, automation, AI prompting, and future skills.

## Stage Definitions

### 1. Experience

Learners see or build something quickly, often with AI assistance, to create excitement and context.

Purpose: motivation and curiosity.

### 2. Understand

Learners study the core ideas behind what they built.

Purpose: foundations.

### 3. Rebuild

Learners recreate or improve the solution with less AI support and more ownership.

Purpose: competence.

### 4. Master

Learners apply the skill to a new real-world problem with limited help.

Purpose: transfer.

### 5. Teach

Learners explain the concept, present their project, mentor someone else, or document their process.

Purpose: proof of understanding.

## Why This Matters

This framework lets IATECH use AI and vibe coding as accelerators without sacrificing fundamentals.

## Consequences

The mission engine, database, tutor dashboard, AI assistant, badges, curriculum, and portfolio must support learning stages.
