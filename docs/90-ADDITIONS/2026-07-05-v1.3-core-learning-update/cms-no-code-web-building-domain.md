# CMS and No-Code Web Building Domain

## Purpose

Many real businesses do not need custom code first. They need a functional, maintainable website or business tool.

CMS and no-code skills help learners solve real problems quickly.

## Core Tools and Concepts

- What a CMS is
- WordPress
- Elementor/page builders
- Gutenberg
- Themes
- Plugins
- Menus
- Pages vs posts
- Forms
- Landing pages
- Basic SEO
- Domains and hosting
- Website maintenance
- When to use CMS vs custom code

## IATECH Principle

> Choose the right tool for the problem.

## Example Missions

- Plan a WordPress website for a local business.
- Build a landing page structure for a training programme.
- Create a website maintenance checklist.
- Compare WordPress vs custom code for a client.
- Design a simple lead capture page.

## AI Prompting

Students should learn prompts for:

- site structure
- page copy
- SEO basics
- plugin selection criteria
- content planning
- client requirements gathering

## MVP Scope

The MVP does not need to host WordPress inside the app. It should teach concepts, planning, decision-making, and project documentation. Practical builds can be external or simulated.
