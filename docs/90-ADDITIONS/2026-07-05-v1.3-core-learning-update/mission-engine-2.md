# Mission Engine 2.0

## Purpose

Mission Engine 2.0 updates the app structure to support the AI-Accelerated Learning Framework.

## Old Structure

Mission → Lessons → Project → Submission

## New Structure

Mission → Experience → Understand → Rebuild → Master → Teach → Evidence

## Mission Fields

Each mission should include:

- problem statement
- target users
- capability tags
- skill tags
- competencies
- learning stage steps
- AI-assisted sprint activity
- foundation lesson
- rebuild task
- mastery challenge
- teaching/presentation activity
- evidence requirements
- badge mapping

## Stage Requirements

### Experience

Quick AI-assisted or guided prototype.

### Understand

Foundation explanations and concept checks.

### Rebuild

Learner rebuilds or improves with reduced AI support.

### Master

Learner applies skill to a new problem.

### Teach

Learner explains, presents, documents, or mentors.

## App Implication

Mission pages should visually show the five learning stages.
