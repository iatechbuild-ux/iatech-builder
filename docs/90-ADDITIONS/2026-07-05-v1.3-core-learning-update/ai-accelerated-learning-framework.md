# AI-Accelerated Learning Framework

## Purpose

This framework defines how IATECH uses AI and vibe coding without weakening foundational learning.

## Core Sequence

**Experience → Understand → Rebuild → Master → Teach**

## Why This Works

Students become motivated when they see results quickly. AI can help create that first spark. But quick results are not mastery.

IATECH uses AI-assisted building to create curiosity, then requires students to understand, rebuild, apply, and explain.

## Stage 1: Experience

Students see a quick result.

Examples:

- Use AI to generate a first landing page.
- Use AI to create a simple Python calculator.
- Use AI to outline a business dashboard.
- Use AI to design automation logic.

The goal is excitement, not mastery.

## Stage 2: Understand

Students learn the foundations behind the result.

Examples:

- What is HTML?
- What is a Python variable?
- What is a dataset?
- What is a sensor?
- What is a CMS?

## Stage 3: Rebuild

Students rebuild or improve the work with reduced AI support.

They must explain what they are changing and why.

## Stage 4: Master

Students apply the same skill to a new problem.

This proves transfer.

## Stage 5: Teach

Students explain, document, present, or mentor.

Teaching is evidence of understanding.

## Universal Rule

AI may help students begin faster, but it must never allow them to skip understanding.
