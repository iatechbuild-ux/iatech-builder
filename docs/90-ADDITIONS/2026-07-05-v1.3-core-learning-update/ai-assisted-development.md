# AI-Assisted Development

## Purpose

AI-Assisted Development is the professional version of what many people call vibe coding.

IATECH may teach the term vibe coding because students and industry may use it, but internally the durable capability is AI-Assisted Development.

## Definition

AI-Assisted Development is the disciplined use of AI to plan, prototype, build, debug, refactor, document, test, and improve software while preserving human understanding and ownership.

## What Students Should Learn

- Plan before prompting.
- Break a project into modules.
- Ask AI for one piece at a time.
- Review generated code.
- Understand before copying.
- Test AI-generated code.
- Debug with AI.
- Refactor with AI.
- Document with AI.
- Deploy with human control.

## Vibe Coding Role

Vibe coding is useful for fast prototyping and motivation.

It should appear mainly in the **Experience** stage.

It should not replace:

- foundations
- debugging
- code understanding
- testing
- deployment discipline

## Student Workflow

1. Define the problem.
2. Plan the solution.
3. Prompt AI for a small first version.
4. Study the output.
5. Rebuild or edit manually.
6. Test.
7. Improve.
8. Deploy.
9. Explain.
