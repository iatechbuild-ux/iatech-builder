# Future Builder Framework

## Purpose

This framework defines *what an IATECH learner is becoming*. It keeps the curriculum from drifting into a random pile of trendy topics: every lesson, mission, and badge must map to at least one capability here, and every capability maps to competencies researched in [`01-RESEARCH/`](../01-RESEARCH/README.md).

## The five capabilities

### 1. I Can Think
Critical thinking, problem solving, systems thinking, computational thinking, decision-making, reflection.

### 2. I Can Communicate
Writing, speaking, presenting, storytelling, explaining technical ideas in plain language.

### 3. I Can Build
Web development, Python, AI-assisted workflows, Git/GitHub, deployment; databases and APIs in later pathways.

### 4. I Can Create Value
Product thinking, design thinking, user research, business-process improvement, fundamentals of entrepreneurship, marketing, and sales.

### 5. I Can Lead
Teamwork, mentorship, responsibility, initiative, community impact.

## Capability → competency map

| Capability | Primary competencies (see 01-RESEARCH) |
|---|---|
| Think | critical-thinking, systems-thinking, computational-thinking, problem-solving |
| Communicate | (embedded in every mission's Present + Reflect steps) |
| Build | web-development, python, prompt-engineering, ai-literacy |
| Create Value | product-thinking, design-thinking, problem-solving |
| Lead | (assessed at the Leadership mastery level across all competencies) |

## How the app uses this framework

The framework is not decoration — it drives real behavior:

- **Placement** measures a learner across these competencies to recommend a pathway.
- **Missions** declare which competencies they develop.
- **Badges** are awarded per competency at a demonstrated mastery level.
- **Portfolios** are tagged by competency so parents and schools see a skills profile, not just a list of projects.
- **Tutor feedback** is framed by the competency the mission targets.

## The curriculum rule

Every lesson, mission, and project maps to at least one capability. If it maps to none, it does not belong in the curriculum. See the mechanism for *levels* of each capability in [`mastery-model.md`](mastery-model.md).
