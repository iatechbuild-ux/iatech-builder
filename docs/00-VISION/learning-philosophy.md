# Learning Philosophy

## Core belief

Children and teenagers can build meaningful solutions when given the right mindset, structure, guidance, and feedback. Capability is developed, not innate.

## Theoretical grounding

The model is deliberately eclectic, drawing on established learning science rather than a single trend:

- **Constructionism (Papert):** people learn best by building shareable, personally meaningful artifacts. Hence missions, not lectures.
- **Cognitive Load Theory (Sweller):** introduce one new concept at the point of need; avoid front-loading theory that overloads working memory. Hence just-in-time concepts.
- **Productive failure (Kapur):** let a project reveal a gap *before* teaching the fix; the struggle primes the learning.
- **Retrieval and spacing:** competencies recur across missions so they are practiced repeatedly, not taught once.
- **Formative assessment (Black & Wiliam):** feedback is frequent, specific, and improvement-oriented; revision is expected, not punished.
- **Metacognition:** reflection is a required step, because naming what you learned and what failed is what makes it stick.

## The learning loop

Discover → Question → Think → Learn → Practice → Build → Test → Improve → Deploy → Present → Reflect

Not every mission uses all eleven verbs with equal weight, but every mission is a subset of this loop in this order, and every mission ends with **Reflect**.

## Operating principles

- Start from a real-life scenario, ideally local.
- Teach a concept only when a mission needs it.
- Make thinking visible (predictions, decision logs, reflections).
- Let projects expose gaps; treat the gap as the teachable moment.
- Tutors guide with questions; they do not lecture or hand over answers.
- AI is a collaborator to be verified, never an authority to be trusted.
- Reward improvement and explanation over first-try correctness.

## The single biggest mistake we refuse to make

Teaching theory, stacks, and abstractions while ignoring real problems and the people who have them. If a lesson cannot answer "whose problem does this help solve?", it does not ship.
